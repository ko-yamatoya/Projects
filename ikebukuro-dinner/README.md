# 池袋、4人で。

JR池袋駅から歩ける範囲の飲食店を、**評点の意味を先に調べてから**絞り込んだ40軒の地図つき一覧。
4人で店を決めるときに、そのまま送りつけられるページ。

**→ https://ko-yamatoya.github.io/Projects/ikebukuro-dinner/**

## 何が見られるか

- **地図** — 40軒のピン。ピンの**文字がジャンル**、**色が夜の予算**（単一色の4段階。濃い=安い）
- **絞り込み** — ジャンル／予算／4人で使える個室／飲み放題／ネット予約可／駅5分以内／出口。
  チップに**その条件で何軒残るかの件数**が出る（0件のチップは押せない）
- **並べ替え** — 予算が安い順（既定）／評価が高い順／駅から近い順／五十音順
- **カードと地図の連動** — カードを押すと地図がその店へ飛び、ピンを押すとカードまでスクロールする
- **絞り込みはURLに入る** — `#g=korean&b=3000` の形。絞った状態のまま人に送れる
- 各店に **食べログとホットペッパーの評点・口コミ件数／予算／徒歩分数と出口／席と個室／飲み放題／
  名物／100〜150字の紹介／低評価口コミの割合／直近の口コミ月／取得元サイト**

## 採用ボーダーと、その根拠

点を見る前に、**各サイトの点数が何を意味するか**を調べてからボーダーを決めた。
ページのフッターにも同じ内容が載っている。

### 食べログ

| | |
|---|---|
| 仕組み | 単純平均ではなく、ユーザーごとの影響度で重みづけ。口コミ2〜3件では高得点がつかない。月2回更新 |
| 公式の分布 | 4.00以上＝上位約0.07% ／ 3.50以上4.00未満＝上位約3% ／ 3.50未満＝約97% |
| 実測（この一覧の母集団） | 池袋・夜¥2,000〜6,000の**1,149軒**で、3.50以上＝上位**2.2%**、3.45以上＝**10.3%**、3.40以上＝**17.4%** |
| **採用ボーダー** | **3.40以上 かつ 口コミ100件以上**（上位17.4%） |

3.40以上の200軒は最少でも口コミ90件・中央値354件だったので、件数条件は実際にはほぼ効かない。
点数が上がるには件数が要る設計だから、これは想定どおり。

### ホットペッパーグルメ

| | |
|---|---|
| 仕組み | 2026年1月29日に口コミを刷新。審査を通れば良い体験も悪い体験も全掲載。評点は「刷新以降に投稿され審査を通過した口コミの**直近1年平均**（5件未満なら直近5件）」を**週次**更新、1人1件 |
| 実測 | 池袋の掲載店から無作為160軒を調べ、評点が出ていたのは78軒。**中央値4.3・平均4.22**。**4.0以上は上位76.9%**（＝ほぼ全店）、4.4以上で38.5%、4.5以上で26.9% |
| **採用ボーダー** | **4.40以上 かつ 算出対象10件以上**（この母集団の上位38.5%） |

「ホットペッパーは4.0以上が優良」という一般的な目安は、**このサイトの分布では意味を持たない**。
甘い側のサイトなのでボーダーを引き上げた。

### ぐるなび — 使わなかった

エリア一覧にも店舗一覧にも**点数・口コミ件数の表示が無い**（実際に取得して確認）。評点の情報源にならない。

### Googleマップ — 使えなかった

分布としては、上野485軒の調査で平均3.9点・4.0〜4.9点が44%、口コミの多い店は3.8〜4.0に収束する。
消費者調査（n=500・2025年1月）では「3.8以上を基準にする」が約半数、「30件以上で信用する」が51.4%。
つまり足切りに使うなら3.8が妥当。

**ただし、APIキー無しで点数・口コミ件数を安定して取得する手段が無いことを実測で確認した**
（Mapsの地図ページ／検索／各種公開エンドポイント／リーダープロキシをすべて試して取得不可）。
よって自動フィルタには組み込めていない。一般客の母数が大きい側の実感は
**ホットペッパーの直近1年平均**で代替し、各店にGoogleマップへのリンクを置いて最終確認を委ねている。

### 2サイトで裏を取る（2段構え）

- **A：食べログ 3.40以上／100件以上 かつ ホットペッパー 4.40以上／算出対象10件以上**
- **B：ホットペッパーに掲載が無い店**は2サイト目を持てないので、食べログ側を一段厳しくして
  **3.45以上（上位10.3%）かつ口コミ200件以上**

Bを設けた理由：ホットペッパーは**広告出稿している店だけを載せる媒体**で、非掲載は「評価が低い」ではなく
「出稿していない」を意味する。実際、食べログ3.38以上の239軒のうちホットペッパーに評点があるのは
88軒（37%）だけで、2サイトを機械的に必須にすると池袋の大衆酒場・もつ焼き・個人店が丸ごと落ち、
チェーンの個室系に偏った。それは「外れを出さない」という目的に反する。

### 低評価チェック

- 候補112軒すべてで食べログの評価分布（1.0〜5.0の人数）とホットペッパーの星分布を数え、
  **2点台以下の割合**を算出。中央値3.9%・上位10%でも6.9%・最大11.3%で、
  当初決めた「20%以上なら不採用」に触れる店は**無かった**。掲載40軒は最大でも**5.2%**
- 「不衛生」「接客が悪い」「提供が異常に遅い」「会計が話と違う」に当たる語で全候補の口コミ本文を
  機械検索。当たった17軒は本文を読み、**複数人が繰り返し訴えている致命的な指摘は無い**ことを確認した
- 候補112軒すべてに**直近1年以内の口コミ**があることを訪問月で確認

### 4人で使えるかの最終フィルタ

- **ネット予約または電話予約ができること**。この条件で「三福」「やきとん千登利」「ます家」
  「立喰さくら寿司」などの人気店が落ちた。**立ち飲み・センベロ系は予約を受けない店ばかりで、
  この条件と両立しないため1軒も入っていない**
- カウンターのみ・十数席の店は外した
- 「個室あり」は**4人で通る個室があるとき**だけ付く。10名〜しか無い個室は数えていない
- ジャンルが偏らないよう配分（居酒屋4／個室・宴会3／焼き鳥もつ焼き3／海鮮5／焼肉5／中華4／
  韓国1／エスニック5／バル・イタリアン6／ビア・ワイン2／そば・鍋2）

## ファイル

| | |
|---|---|
| `index.html` | ページ本体。CSSとJSは中に入っている。地図は `vendor/` の Leaflet |
| `data.json` | 40軒のデータ（正本） |
| `data.js` | `data.json` と同じ中身を `window.__DATA__` に入れた生成物。`file://` でも開けるようにするため |
| `tools/` | 収集から生成までのスクリプト一式（下記） |
| `vendor/` | Leaflet 同梱 |

## データの作り直し方

`tools/` の中で順に走らせる。HTTP応答は `cache/` に貯まるので、途中で止めても続きから再開できる。

```bash
cd tools
python3 tb_sweep.py      # 食べログ 池袋・夜¥2,000〜6,000 を評価順に掃引 → tabelog_all.json
python3 tb_detail.py     # 3.38以上の店の詳細（座標・席・個室・予約可否）→ tabelog_detail.json
python3 hp_sweep.py      # ホットペッパー池袋の全ジャンル索引（1,107軒）→ hpg_index.json
python3 join.py          # 店名＋座標(250m以内)で食べログ↔ホットペッパーを突合 → join.json
python3 hp_report.py     # 突合できた店の評点・星分布・口コミ → hpg_reports.json
python3 hp_baseline.py   # 無作為160軒でホットペッパー評点の分布を測る → hpg_baseline.json
python3 hp_store.py      # 店舗ページとコース（飲み放題の価格）→ hpg_store.json / hpg_courses.json
python3 tb_neg.py        # 食べログの評価分布と直近の口コミ → tabelog_neg.json
python3 menu_fetch.py    # 料理メニュー（名物の裏取り）→ menus.json
python3 build.py         # data.json / data.js を書き出す
```

- 掲載する40軒は `tools/final_list.py`、紹介文と名物は `tools/content.py`、
  フッターの根拠は `tools/footer.html` に置いてある。ここを直して `build.py` を流し直す
- `tools/valpal.py` は地図のピンの色を検証するスクリプト。予算の4段階は
  ΔL≥0.105・彩度≥0.10・地図面に対するコントラスト≥3.17:1 を満たすことを確認済み
- アクセス間隔は0.8〜1.0秒。`cache/` はコミットしない

## 断り書き

- 評点・営業情報は **2026年8月29日**時点。食べログは月2回、ホットペッパーは週次で更新される
- 徒歩分数は JR池袋駅（35.72953／139.71107）からの**直線距離**を分速80mで割った目安
- 飲み放題コースの価格は掲載時点の税込表示。内容も価格も変わる
- 取れなかった項目は推測で埋めず「情報なし」と書いてある
