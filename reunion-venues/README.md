# 15名の同窓会 店さがし（渋谷・新宿）

渋谷・新宿で **15名が個室か貸切で入れて、日曜の夜も営業していて、飲み放題付きで1人5,000円以内** に
収まる店を、食べログとホットペッパーグルメのデータで絞り込み、地図と一覧にまとめたページ。
幹事同士で店を決めるときに、URLをそのまま送れる形にしてある。

**→ https://ko-yamatoya.github.io/Projects/reunion-venues/**

## 公開にあたって載せていないもの

- 会の名前・学校名・参加者や幹事の名前・連絡先・出欠状況は、ページにもデータにも入れていない
- 載っているのは店の公開情報（店名・住所の地図位置・評点・コース・店の電話番号）だけ
- 検索エンジンに載らないよう `noindex` を付けている

## 何が見られるか

見やすさ優先で、1枚のカードに「いくら・なぜおすすめ・どこで確かめるか」だけを置いた。

- **上部** — 載せている店の条件（食べログ3.30以上／15名で個室か貸切／飲み放題付き5,000円まで／日曜の夜も営業）
- **地図** — ピンの数字が一覧の番号。「渋谷に寄る」「新宿に寄る」で寄れる
- **絞り込み** — エリア／部屋（個室・貸切）／予算（〜4,000円・〜4,500円）の3つと、「10/25に空き枠が出ている店だけ」
- **並べ替え** — おすすめ順（既定）／安い順／食べログ評価順
- **カード** — 飲み放題付きコースの最安値と**コスパの目安（◎○△）**、**おすすめ理由（2〜3行）**、注意点、
  **食べログ・ホットペッパー・Googleマップへのリンク**（評点と件数つき）、ネット予約できる店は予約ボタン。
  「詳しい情報」に個室・貸切の原文、日曜の営業時間、サービス料、口コミの傾向

### コスパの目安

| | 基準 |
|---|---|
| ◎ | 飲み放題付きコースが3,500円以下、または4,000円以下で飲み放題2.5時間以上 |
| ○ | 4,500円以下 |
| △ | 5,000円まで、またはサイトにコース価格が無い |

コースはホットペッパー掲載のうち、飲み放題が付いていて、15名で使え、日曜に使えるもの。
飲み放題だけのプラン（単品飲み放題）は数えない。

### 楽天ぐるなびを使っていない理由

2026-09-15に店舗ページを取得して確認したが、**点数も口コミ件数も表示されない**（「口コミ」はユーザー投稿写真の欄だけ）。
基準の判定に使えないうえ、店名検索の結果はブラウザ側で描画されHTMLに店舗IDが出ないため、リンクも機械的に張れなかった。

## 選び方

2026年9月15日に取得。数字はすべて実測。

| 段階 | 軒数 | 中身 |
|---|---|---|
| 母集団 | 1,290 | 食べログ「渋谷」「新宿」×「個室あり」「貸切可」×夜¥2,000〜5,999 を評価順に3.20まで掃引（検索ヒット数は渋谷 個室223・貸切1,084、新宿 個室466・貸切1,613） |
| 評点 | 661 | **食べログ3.30以上**（指定）・口コミ50件以上・夜の予算¥4,999以下 |
| 一次ふるい | 156 | 15名の部屋・日曜の夜・業態で落とす（内訳は下） |
| ホットペッパー突合 | 113 | 座標＋店名で突合し、漏れは店名検索で補う（コース価格・口コミ・空き枠を取るため） |
| **掲載** | **15** | 下の基準で絞り、紹介文を書いた |

食べログ3.30以上が母集団のどのあたりか：渋谷は個室あり店の上位40.8%・貸切可店の上位36.7%、
新宿は25.3%・27.9%。3.40にすると渋谷21〜22%・新宿15〜17%まで絞れる。

### 一次ふるいで落ちた661→156の内訳

| 理由 | 軒数 |
|---|---|
| 15名が入る個室も、20名以下の貸切も無い | 311 |
| 日曜の21時以降に営業していない | 90 |
| バー・カフェ・ラーメン・寿司など同窓会の1軒目に向かないジャンル | 73 |
| ライブ・生演奏あり（騒がしさの目安） | 17 |
| 最大予約人数が15名未満 | 9 |
| 立ち飲み・大衆酒場 | 5 |

「スポーツ観戦可」も最初は落としていたが、83軒中75軒がこれで、テレビがあるだけの静かな中華や韓国料理まで
消えていたので条件から外した。

### 156→15に絞った基準

- **15名で使える部屋が確か**なこと。個室の備考で「最大12名」「着席14名」と分かった店は落とした
  （中華バル池湖、人生ポチャ、ballo ballo、ポポリ）
- **日曜の夜に使える飲み放題付きコースが5,000円以内**。平日限定・昼宴会・20:30以降限定・21時以降限定の割安コースは数えない
  （和創作 空は該当コースが無く落ちた。金しゃもじ・渋谷牡蠣屋はコースが5,700円〜）
- **口コミで騒がしさを訴えていない**（23番地・鳥居くぐり・座楽・ハヌリは「全体的に賑やか」「個室でも大きな声が必要」の口コミで外した）
- **低評価が少ない**。食べログで2.5点以下をつけた人の割合を全候補で数え、10%を超える店（黄金屋14%・京町恋しぐれ12%）は外した
- コース価格がサイトに無い店は、評価と部屋が特に良い2軒（万作・4番サード魚真）だけ残し、「電話で相談」と明記した

### 突合の誤りと直したこと

ホットペッパーの店名検索で、地名や一般語（「渋谷」「新宿」「カフェ」「DE」）で引いた結果、
**別の店を同じ店と判定したものが7件**あった（青山シャンウェイ→カラオケパセラ など）。
座標突合でも「○○ 新宿西口店」どうしの類似で**別の店を結んだものが4件**あった。
検索語から地名・一般語を除き、類似度を支店名抜きで測るように直して、全件を突合し直した。掲載15軒はどれも影響を受けていない。

## ファイル

| | |
|---|---|
| `index.html` | ページ本体。CSSとJSは中に入っている。地図は `vendor/` の Leaflet |
| `data.json` | 掲載店のデータ（正本） |
| `data.js` | `data.json` と同じ中身を `window.__DATA__` に入れた生成物。`file://` でも開けるようにするため |
| `tools/` | 収集から生成までのスクリプト一式 |
| `vendor/` | Leaflet 同梱（外部CDNに依存しない） |

## データの作り直し方

`tools/` の中で順に走らせる。HTTP応答は `tools/cache/` に貯まるので、途中で止めても続きから再開できる
（`cache/` と中間JSONはコミットしない）。アクセス間隔は0.8〜1.0秒。

```bash
cd tools
python3 tb_sweep.py            # 食べログ 渋谷・新宿 × 個室あり／貸切可 × 夜¥2,000〜5,999 を評価順に掃引 → tabelog_all.json
python3 hp_sweep.py            # ホットペッパー 渋谷・新宿の個室あり索引 ＋ 開催日・15名のネット空き枠 → hpg_index.json / hpg_avail.json
python3 tb_detail.py           # 3.30以上・50件以上・夜¥4,999以下の店の詳細 → tabelog_detail.json
python3 screen.py              # 15名の部屋・日曜の夜・ジャンル・騒がしさの一次ふるい → screen.json
python3 join.py                # 店名＋座標で食べログ↔ホットペッパーを突合 → join.json
python3 pick.py lists          # ボーダー適用 → shortlist.json / hp_targets.json
python3 hp_store.py            # ホットペッパーの店舗情報・コース・口コミ → hpg_store.json
python3 tb_neg.py              # 食べログの評価分布 → tabelog_neg.json
python3 pick.py dossier        # 候補ごとの資料 → dossier.txt（紹介文を書く材料）
python3 build.py               # content.py の掲載リストから data.json / data.js を書き出す
```

- 掲載する店・並び順・ジャンル・紹介文・注意書きは `tools/content.py`。ここを直して `build.py` を流し直す
- 開催日と人数は `hp_sweep.py`（空き枠の検索条件）と `build.py`（`N`・`CAP`）にだけ置いてある
